# Personal Diary Management System

A Java console-based application that allows users to securely manage personal diary entries with password authentication, date-based search, favorite entries, and dynamic storage using Object-Oriented Programming (OOP) concepts.

## Features

- Password-protected access
- Add new diary entries
- Search entries by date
- Display all diary entries
- Delete entries by ID
- Mark entries as favorite
- View favorite entries
- Date validation
- Dynamic array resizing
- Menu-driven interface

## Technologies Used

- Java
- OOP (Classes, Objects, Encapsulation)
- Arrays
- Exception Handling
- Scanner Class

## Project Structure

- `personalDiary.java` – Main application and login system
- `DiaryManager.java` – Menu handling and user operations
- `Diary.java` – Diary entry management
- `DiaryEntry.java` – Diary entry data model

## How to Run

1. Compile the project:
   ```bash
   javac *.java
   ```

2. Run the application:
   ```bash
   java personalDiary
   ```

3. Enter the default password:
   ```
   1234
   ```
